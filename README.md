# Royal Jackpot — Unity Slot Machine

A small 2D-style slot machine assignment project built in Unity with C#.

## Game overview
- Three reels with the supplied 7, cherries, BAR and bell artwork.
- Each spin costs 10 coins.
- A win occurs only when all three reels show the same symbol.
- A winning spin awards 100 coins.
- Reels animate independently and stop one after another.
- Starting balance: 1,000 coins.
- Restart button resets the balance and game state.

## Requirements
- Unity 2022.3 LTS (or a compatible later Unity version).
- For browser export, install **WebGL Build Support** from Unity Hub.

## Open and run
1. Extract the project ZIP.
2. Open Unity Hub → **Add** → **Add project from disk**.
3. Select the extracted `UnitySlotGame` folder.
4. Open `Assets/Scenes/SlotMachine.unity`.
5. Press the **Play** button.

The game creates its interface at runtime. The supplied artwork is loaded from
`Assets/Resources/SlotArt/`, so keep those filenames and folders unchanged.

## Build a WebGL version
1. In Unity, open **File → Build Settings** (or **File → Build Profiles** in newer versions).
2. Select **WebGL** and choose **Switch Platform**.
3. Add `Assets/Scenes/SlotMachine.unity` to the Scenes In Build list.
4. Open **Player Settings** and set the product name to `Royal Jackpot`.
5. Choose a suitable WebGL template and ensure the build compression setting is supported by your hosting provider.
6. Click **Build** and choose a folder such as `Build/WebGL`.
7. Test the build using a local web server or upload it to a static host. Opening `index.html` directly from the file system may not work because browsers restrict WebGL local file access.

The WebGL build is generated by your local Unity Editor; it is not included in this source archive.

## Bonus / design decisions
- Sequential reel stops create anticipation.
- The balance is checked before a spin so it cannot become negative.
- The spin button is disabled while the reels are moving.
- A restart option is included.
- The random outcome is selected using Unity's `Random.Range`.

## Code structure
- `Assets/Scripts/SlotMachineGame.cs` — runtime UI, reel animation, RNG, win checking and payout.
- `Assets/Resources/SlotArt/` — supplied slot machine artwork and animated GIF reference.
- `Assets/Scenes/SlotMachine.unity` — startup scene.

## Thought process
I kept the implementation intentionally focused on the assessment's required rule: all three visible symbols must match to win. Reel animation is presentation-only; the final result is selected using Unity's random number generator. The game state, balance, payout and UI are kept together in a compact controller for this small assignment. For a larger production game, the reel, economy, and UI responsibilities should be split into separate components.
